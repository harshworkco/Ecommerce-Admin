DATABASE TABLES
---------------
admins(id, name, email UNIQUE, password_hash, role[super_admin|admin|manager], is_active, created_at, updated_at)
products(id, name, description, price DECIMAL, stock INT, category, image_url, is_active, created_at, updated_at)
users(id, name, email UNIQUE, phone, password_hash NULL, address, is_active, created_at, updated_at)
orders(id, user_id NULL, customer_name, customer_email, total_amount DECIMAL, status[pending|confirmed|shipped|delivered|cancelled], payment_status[unpaid|paid|refunded], shipping_address, created_at, updated_at)
order_items(id, order_id FK CASCADE, product_name, quantity, price, created_at)
payments(id, order_id FK CASCADE, user_id NULL, amount DECIMAL, method[cod|card|upi|netbanking|wallet], status[pending|success|failed|refunded], transaction_id UNIQUE, created_at, updated_at)

ALL APIS
--------
AUTH (public register/login, protected me):
POST /api/auth/register {name,email,password,role?} -> 201 {admin,token}
POST /api/auth/login {email,password} -> 200 {admin,token}
GET  /api/auth/me (Bearer) -> 200 {admin}

DASHBOARD (Bearer required):
GET /api/dashboard/stats -> {totalAdmins,totalOrders,totalRevenue,totalUsers,totalProducts,pendingOrders}
GET /api/dashboard/recent-orders?limit=5 -> {orders[]}
GET /api/dashboard/sales-chart?days=7 -> {chart[{date,orders,revenue}]}
GET /api/dashboard/order-status -> {breakdown[{status,count}]}

ORDERS (Bearer):
GET  /api/orders?search=&status=&page=1&limit=10 -> {total,page,orders[]+item_count}
GET  /api/orders/:id -> {order,items[]}
POST /api/orders {customer_name,customer_email?,shipping_address?,status?,payment_status?,total_amount? OR items[{product_name,quantity,price}]} -> 201, total auto-sums items, transaction
PUT  /api/orders/:id/status {status} -> status update
PUT  /api/orders/:id {customer_name?,customer_email?,total_amount?,status?,payment_status?,shipping_address?}
DELETE /api/orders/:id (cascades items+payments)

USERS / CUSTOMERS (Bearer):
GET  /api/users?search=&is_active=&page=&limit= -> {total,users[]+order_count}
GET  /api/users/:id -> {user,orders[10]}
POST /api/users {name,email,phone?,password?,address?} -> 201
PUT  /api/users/:id {name?,email?,phone?,password?,address?}
PUT  /api/users/:id/status {is_active:true/false} -> block/unblock
DELETE /api/users/:id

PAYMENTS (Bearer, syncs orders.payment_status: success->paid, refunded->refunded, else unpaid):
GET  /api/payments?search=&status=&method=&page=&limit= -> {total,payments[]+customer_name,collected}
GET  /api/payments/:id -> {payment}
POST /api/payments {order_id,amount?(defaults to order total),method?,status?,transaction_id?,user_id?} -> 201
PUT  /api/payments/:id/status {status}
DELETE /api/payments/:id

ANALYTICS (Bearer):
GET /api/analytics/overview -> {totalOrders,totalRevenue,avgOrderValue,totalUsers,collectedPayments,last30dOrders,last30dUsers}
GET /api/analytics/revenue?days=30 -> {days,chart[]}
GET /api/analytics/top-products?limit=5 -> {products[]} from order_items
GET /api/analytics/top-customers?limit=5 -> {customers[]} by spent
GET /api/analytics/payments -> {byMethod[],byStatus[]}
GET /api/analytics/user-growth?days=30 -> {days,chart[]}

PRODUCTS (Bearer, new Step 7):
GET  /api/products?search=&category=&is_active=&page=&limit= -> {total,products[]}
GET  /api/products/:id -> {product}
POST /api/products {name,price,stock?,description?,category?,image_url?} -> 201
PUT  /api/products/:id {name?,price?,stock?,description?,category?,image_url?,is_active?}
PUT  /api/products/:id/stock {stock}
DELETE /api/products/:id

NOTES
-----
- MCP MySQL tool is READ-ONLY, so CREATE DATABASE/TABLE via MCP fails; backend auto-creates on npm start (verified working).
- orders.user_id is nullable, no FK to users yet; users link via user_id OR customer_email (see users list order_count, users/:id orders).
- order_items uses product_name string snapshot, not product_id FK; products table is standalone catalog.
